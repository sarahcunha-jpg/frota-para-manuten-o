Os dados são gravados no localStorage do navegador. Faça backup regularmente com "Exportar dados" para não perder as informações ao limpar o navegador ou trocar de dispositivo.

Baixa um arquivo JSON com todos os dados do sistema.

📥 Importar

Substitui todos os dados atuais pelo conteúdo do arquivo. Faça exportação antes, por segurança.
